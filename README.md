# 算数かさ・容量 (Volume and Capacity)

小学2〜3年生向け 算数「水のかさ・容量」（L・dL・mL）の体験型学習＆A4プリント自動作成Webアプリケーション。

- **GitHub リポジトリ**: [git@github.com:Satoshi-Hiramatsu/Volume-and-Capacity.git](git@github.com:Satoshi-Hiramatsu/Volume-and-Capacity.git)
- **デプロイ環境**: Cloudflare Workers / Static Assets
- **対象学年**: 小学校2年生〜3年生（保護者・指導者対応）

---

## 🌟 主な特徴

1. **教育水準の高品質SVGグラフィック**:
   - 1Lます、1dLます、メスシリンダー、計量カップ、牛乳パック、ペットボトルなどの多層レイヤー高精細ベクターアート。
   - ガラスの光沢・透明感、水面のメニスカス（表面張力湾曲）、正確な10分割目盛り線。
   - 親しみやすいマスコット「ドロップくん（カサの妖精）」の表情演出。
2. **PC & スマートフォンの完全レスポンシブ対応**:
   - スマホの小さな画面でも押し間違えない 48px〜56px のタッチターゲット。
   - UDフォント（BIZ UDPGothic）採用で、子どもにも視認性抜群。
3. **インタラクティブな「画面でまなぶ」モード**:
   - **へんしんラボ**: 水を注ぐ・抜くシミュレーション。L・dL・mLの目盛りがリアルタイム連動。「1dLブロック」表示で1Lの中に1dLが10個入る構造を可視化。
   - **かずをつくる**: 1Lます、1dLます、10mLを増やして「ならんでいる容器たち」を視覚的に体験。
   - **けいさん（くりあがり実験）**: 10dL集まると1Lに変身するアニメーション、1Lを10dLに崩す繰り下がりシミュレーション。
   - **みぢかなかさ図鑑**: 牛乳パック（1L）、ペットボトル（500mL）、コップ（200mL）、スプーン（15mL）など生活の中の量感比較。
4. **れんしゅうモード（10問テスト）**:
   - ☆1（初級）〜☆4（発展）から選んでチャレンジ。
   - 即時判定、ステップごとの分かりやすい図解アニメーション付き解説。
5. **本格的なA4プリント作成（印刷・PDF）**:
   - JIS A4縦（210mm × 297mm）レイアウト。
   - 難易度・問題パターン（P1〜P10）・問題数（6/8/10問）を自由に選んで自動生成。
   - 解答シート自動作成（赤字で答えと目盛りハイライト・ポイント解説）。
   - URLシード値対応により、同一URLで全く同じプリントをいつでも再印刷可能。

## 🚀 開発とデプロイ

### ローカルでの起動
```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (wrangler)
npm run dev
```

### Cloudflare へのデプロイ
```bash
npm run deploy
```
